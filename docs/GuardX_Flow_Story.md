# Mobile Patrol Flow – Ek Paragraph Ki Story

Admin pehle **Organization** (jaise Ark Globe Academy) select karta hai, phir **Mobile Patrol** ke andar **Regions** tab pe map pe area draw karke region bana leta hai aur save karta hai; usi region ke andar **Patrol Sites** add karke har site ka naam, address, customer, reference numbers aur location (lat/long) **Site Details** tab mein bhar deta hai. **Portal Schedule** tab se wo har site pe kab kab patrol visit hogi (din aur time) set karta hai, **Alarm Company & Site Contact** se alarm company, monitoring company aur callout contacts add karta hai, **Site Document** se documents attach karke “Allow All Staff to View” jaisi options deta hai, **Site Codes & Instruction** mein site ke codes aur instructions likhta hai, **Location/Checkpoint** mein checkpoints (QR/NFC, geofence, distance threshold) define karta hai, aur **Incident Report** tab se incident/survey types ko enable ya disable karta hai — sab mila kar **Patrol Site Assign To [Organization]** complete hota hai aur **Save** pe click karke site active ho jati hai. Phir **Runsheets** tab pe ja kar admin **Runsheet** banaata hai (name, region, din, start/end time) aur **Add Patrol Site** se har patrol site ko runsheet mein add karke batata hai ke kis din kis time between kitni visits honi hain aur expected time kya hai; is tarah **Regions → Patrol Sites → Site Details/Schedule/Contacts/Documents/Codes/Checkpoints/Incident → Runsheets → Add Patrol Site** ka pura flow complete hota hai aur staff ki **submitted availability** list ke sath patrol schedule ready ho jata hai.
