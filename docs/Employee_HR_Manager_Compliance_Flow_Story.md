# Employee Details, HR Details, Manager Details & Submitted Compliance – Flow (Ek Paragraph)

Admin **Employee Details** screen pe employee list se kisi employee ko select karta hai (jaise Leticia Octavio) aur uski details (First Name, Last Name, Email, Employee ID, PIN, Reference Number) aur **Access Privileges** (Super Admin, Admin, Manager, Employee, Sub-contractor) set karta hai; **Save** ya **De-Activate** se profile update hota hai. **Request Compliance** pe click karke modal open hota hai jahan company ke compliance items (Security License types, Renewal types) list hoti hain — admin checkboxes se select karke **Request Compliance** click karta hai aur us employee ke liye compliance request create ho jati hai. **HR Details** tab pe ja kar admin employment type (Full-time, Part-time, Contractor, Intern), start/end dates, DOB, place/country of birth, notice period aur **Add New HR Note** se note add karta hai; **Manager Details** tab pe agar wo manager hai toh **Select the sites that [Name] can manage** list mein sites check/uncheck karke assign karta hai aur **Save** se manager–site assignment update ho jata hai. **Submitted Compliance** section mein staff ki submitted compliance list (Staff Name, Compliance Name, License#, Expiry, Type, Attachment) dikhti hai — admin **Approved** toggle se approve karta hai ya **Cancel Request** se request cancel karta hai. Is tarah **Employee List → Employee/HR Details → Access Privileges → Request Compliance → HR Notes → Manager Site Assignment → Submitted Compliance (Approve/Cancel)** ka pura flow complete hota hai; dashboard pe **Live Operations**, **Reminder/Compliance**, **Availability/Leave Request**, **Subcontractor Reminder** aur **Published Vs Unpublished** schedules bhi isi data pe depend karte hain.
